# LUCKY ONE

直接打开 `index.html`，或将 `index.html`、`app.js`、`upgrade.css` 放在同一目录下部署为静态网站。

## 分组抽取

1. 在「分组」创建并命名抽取池；名称可直接编辑。
2. 在「候选人」选择目标分组，粘贴名单或导入每行一个姓名的 TXT/CSV。也可在候选人卡片中调整所属分组。
3. 首页默认三列，用 `−` / `＋` 调整为 1–6 列，每列独立选择分组、未分组或全部候选人。
4. 点击开始，每列抽取一人。同一轮、后续轮次都不会重复抽取已中选人员。多列选择同一组时，需要有足够的不同候选人；不足时整轮不开始。

抽中即保存姓名、轮次、列号、抽取池、所属分组及时间，无需先评分。已抽中人员从候选列表移除，但保留积分和历史记录。记录侧栏可滚动查看全部历史。

记录侧栏的「清空记录」仅删除抽取记录，保留名单、分组、积分、累计统计和已抽中状态，不会让已抽中人员重新入池。

每人只能属于一个分组，同名视为同一人；重名请使用编号区分。修改分组、重新导入姓名或清空剩余候选人都不会让已中选人员重新入池。

## 数据

数据保存在当前浏览器的 `localStorage`，刷新后保留。沿用旧版 `pickone_data` 存储键；旧版记录中的人员会自动排除。旧版未评分且未记录的抽取无法恢复。

设置中可导出/导入完整 JSON 备份，包含分组、列配置和抽取记录。导入会替换当前数据；重置全部数据会清空记录。更换浏览器或网站地址前可先导出备份。

## 验证

安装 Playwright 且本机有 Chrome 时运行：

```sh
node --check app.js
node tests/draw.spec.cjs
```

测试使用临时本地服务器和独立浏览器上下文，不接触日常使用的名单。覆盖分组、多列抽取、交叠抽取池、人数不足、刷新持久化、旧数据迁移、备份往返、计分及移动端布局。
